# 🏛️ VortexPCE Project Governance

This document describes the project governance structure for **VortexPCE**.

---

## 👥 Roles & Responsibilities

### Project Lead & Benevolent Dictator for Life (BDFL)
* **Dr. Omar Y. Tahboub** (Creator & Principal Architect)
  * Retains ultimate authority over architectural decisions, release tags, and core mathematical algorithms.

### Maintainers
* Review pull requests.
* Maintain CI/CD pipelines, documentation, and Docker images.
* Triaging security advisories and bug reports.

---

## 📋 Decision Making Process

1. **Minor Fixes & Documentation:** Merged via PR approval by any maintainer.
2. **Core Algorithmic / PCEP Changes:** Requires review and explicit approval by the Project Lead.
3. **Release Tagging:** Only the Project Lead can sign and publish official release tags (`v1.0.0`).
